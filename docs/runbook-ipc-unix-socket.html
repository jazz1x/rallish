Unix Domain Socket IPC
수동 검증 가이드

사전 준비: Go 1.25+, macOS/Linux, ~/.rallish/ 디렉토리 쓰기 권한.
각 단계별로 명령어를 복사-붙여넣기 할 수 있으며, 예상 출력 결과를 함께 확인합니다.

0

원샷 전체 검증

아래 전체 블록을 복사-붙여넣기 하면 빌드 → 데몬 실행 → 모든 검증 → SIGTERM → 클린업까지 한 번에 진행됩니다.

cd /path/to/rallish
make build
rm -rf ~/.rallish

(
  cd "$(pwd)"
  ./dist/rallish daemon &
  DAEMON_PID=$!
  sleep 2

  echo "=== 1. 유닉스 소켓 존재 확인 ==="
  ls -la ~/.rallish/rallish.sock

  echo "=== 2. 소켓 경로 파일 확인 ==="
  cat ~/.rallish/socket

  echo "=== 3. 포트 파일 확인 ==="
  cat ~/.rallish/port

  echo "=== 4. 유닉스 소켓으로 A2A discovery ==="
  SOCKET=$(cat ~/.rallish/socket)
  curl --unix-socket "$SOCKET" -s http://rallish.local/.well-known/agent.json | head -c 200
  echo

  echo "=== 5. TCP로 A2A discovery ==="
  PORT=$(cat ~/.rallish/port)
  curl -s "http://127.0.0.1:${PORT}/.well-known/agent.json" | head -c 200
  echo

  echo "=== 6. SIGTERM 그레이스풀 셧다운 ==="
  kill -TERM "$DAEMON_PID"
  wait "$DAEMON_PID"
  EXIT=$?
  echo "Exit: $EXIT"

  echo "=== 7. 잔여 파일 클린업 확인 ==="
  ls ~/.rallish/rallish.sock 2>/dev/null && echo "FAIL socket" || echo "OK socket"
  ls ~/.rallish/socket    2>/dev/null && echo "FAIL socket file" || echo "OK socket file"
  ls ~/.rallish/port      2>/dev/null && echo "FAIL port" || echo "OK port"

  [ "$EXIT" -eq 0 ] && echo "✅ 통과" || echo "❌ 실패"
)
예상 출력
Exit: 0 OK socket OK socket file OK port ✅ 통과
⚠ 주의
cd /path && ./dist/rallish daemon & 형태로 실행하면 bash의 $!가 서브셸 PID를 가리킵니다. 데몬 PID를 올바르게 얻으려면 위 예시처럼 cd와 ./dist/rallish daemon &를 분리하거나 (...) 서브셸 안에서 실행하세요.

문제 해결

증상원인해결
Exit: 143 $!이 서브셸 PID를 가리킴 cd와 ./dist/rallish daemon &를 분리 실행
curl: (7) 데몬이 실행되지 않음 ~/.rallish/socket 내용과 로그 확인
golangci-lint 실패 v1 설정 스키마 본 저장소는 v2 사용 — 다운그레이드 금지
포트 파일 누락 TCP 리스너 실패 데몬 로그에서 listen: 에러 확인
