## Summary

End-to-end polish on the `rallish` CLI surface modeled on the
oh-my-borory `omb` CLI (PyClack glyphs + npx-skills-add interactive
pattern), plus a real home for human-set settings (`rallish config`)
and a compact one-screen `bootstrap` wizard. No behavioral changes to
the rally / squash / daemon engines — purely the user-facing layer.

| What | Why it matters |
|---|---|
| `internal/ui` SSOT (color tokens · ◇ ✓ ■ ⚠ ◆ └ glyphs · prompt/confirm/select · aligned table) | One place to change CLI presentation; auto-falls-back to plain ASCII under `NO_COLOR` / pipe / CI. |
| `rallish config` group (list / get / set / path / edit) | First-class home for `default_preset`, `default_adapter`, `coding_cli`, `editor`, `wait_mode`, `telemetry`. Atomic save, enum validation, source attribution (file / env / default). |
| `rallish bootstrap` rewrite — 4 steps, ≤ one screen | Coding-CLI assistants no longer truncate their session discography on the next launch; the wizard collects only the 3 most-asked-about values, `--yes` for CI. |
| `rallish add` interactive picker (bare invocation) | `npx skills add` parity — type → name → scope wizard when no positional args supplied. |
| Grouped `--help` (Setup / Rally / Manage / System) + `--version` + new `doctor` view | Discoverable command tree; structured `doctor.Inspect()` returns typed `Check` records that the CLI renders with glyphs. |
| `scripts/check-no-raw-ansi.sh` + lefthook hook | Fails commits that introduce raw `\x1b[` escapes outside `internal/ui` — keeps the SSOT intact. |
| `.claude/settings.json` allowlist | Pre-approves the 6 most-frequent read-only/static project commands so future autonomous cycles run in regular permission mode (NOT bypassPermissions, which hard-blocks long loops). |
| Docs sweep — README × 3 locales + CHANGELOG × 3 locales under `[Unreleased]` | Quick-start blocks reflect the new flow; readers in en/ko/jp get the same surface. |

## Compatibility

- **No breaking flag changes.** All existing `rallish` commands keep
  their current flags and exit codes; the `add`/`bootstrap`/`doctor`
  output is restyled but the meaningful strings tests assert against
  ("Installed preset solo-ralph", "rallish squash --preset …", etc.)
  are preserved.
- **`~/.rallish/config.yaml` is new but optional.** Missing file =
  built-in defaults; `bootstrap` and `config edit` lazily seed it.
- **No data migration required.** Existing rally sessions / sockets
  under `~/.rallish/` are untouched.
